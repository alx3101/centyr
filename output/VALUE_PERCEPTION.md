## 1. Current Perception Issues

- **Wrong category label**: "SaaS AI-powered product photo processor" places Centyr in the generic background-remover category (remove.bg, PhotoRoom, Canva). That comparison set makes Centyr look like a commodity. The actual category is "EU marketplace image compliance engine" — a category it currently owns alone. The category name determines the comparison set; fix the category and the competition changes entirely.
- **Feature-first descriptions throughout**: "BiRefNet AI background removal," "automatic centering," "marketplace format presets" are technically accurate but describe inputs rather than outcomes. Buyers do not pay for AI models — they pay for the Zalando application clearing review on first submission. Every description needs to start with the result.
- **Bonus stack perceived as free blog content**: All five bonus components are named as "Cheat Sheet," "Checklist," "Guide," and "Template" — formats universally associated with lead magnets and free opt-in content. When a prospect sees these labels they discount the stated value immediately, regardless of the content quality. A €47 "Marketplace Spec Master Sheet" reads like a free PDF. The same content renamed "Zero-Rejection Spec Vault" with a before/after compliance result reads like a tool.
- **Three guarantee options with no public commitment**: The offer document lists Options 1, 2, and 3. None is named or published. This means the risk-reversal layer — which is the most powerful single conversion lever in the offer — currently produces no conversion benefit because it is not visible to the prospect.
- **Live hero copy does not match documented strategy**: "The Right Format for Amazon, eBay, Etsy and Zalando — Automatically" is benefit copy framed as a convenience. The documented strategy (OFFER_ANGLES.md) identifies the Zalando rejection trigger as the highest-converting hook. The best copy is written; it is just not deployed. This gap represents active, measurable conversion loss on every visitor the current page receives.
- **Pricing published as a range**: "€29–€99/month" signals internal uncertainty to anyone who reads it. Anchoring works only against a specific number. A range cannot be anchored against — it just creates confusion about what the real cost is.
